# 网页 A / 网页 B 操作流程说明

本文说明体育场人群检测系统中 **大图滑窗（网页 A）** 与 **拼接去重统计（网页 B）** 的用途与操作步骤。  
服务由 `app_win.py` 启动，默认端口 **5000**（与 `PORT` 配置一致）。

---

## 访问地址

| 页面 | 地址 | 作用 |
|------|------|------|
| 体育场主页（单图/文件夹检测） | `http://localhost:5000/` | 日常选图检测，侧栏可进入 A/B |
| **网页 A** | `http://localhost:5000/a` | 大图 **1280 滑窗** → 每块 ONNX 推理 → 输出 JSON |
| **网页 B** | `http://localhost:5000/b` | 接收 A 的 JSON → **坐标还原** → **全局 NMS** → 人数、YOLO txt、CSV |

---

## 网页 A：大图滑窗检测（Pipeline A）

### 适用场景

- 单张看台照片 **分辨率很大**，直接整图检测显存吃紧或人物过小。
- 需要按与训练/评估一致的 **1280 窗口 + overlap** 切块推理。

### 操作步骤

1. 浏览器打开 **`http://localhost:5000/a`**（或从主页侧栏点 **「网页 A：大图滑窗」**）。
2. 在页面顶部可用 **「打开网页 B」** 随时跳到 B（不必先跑 A）。
3. 设置参数（可选，有默认值）：
   - **overlap**：相邻窗口重叠像素，默认 `200`（与常见评估脚本 stride = 1280 − overlap 一致）。
   - **conf**：单块推理置信度阈值，默认 `0.35`。
   - **iou**：单块内 NMS 的 IoU，默认 `0.25`。
4. 点击 **「选择大图」**，选中一张 JPG/PNG 等。
5. 点击 **「运行 pipeline_a」**，等待处理（大图可能较慢）。
6. 下方文本框会出现 **JSON**，包含：`orig_w`、`orig_h`、`tiles[]`（每块的 `x0,y0,w,h` 与 `persons`）、`sum_raw`（各块人数之和，**未做跨块去重**）。
7. 后续任选其一：
   - **「② 带着 JSON 去网页 B」**：把结果写入浏览器缓存并 **跳转到 B**，B 会自动填入 JSON（推荐）。
   - **「复制 JSON」**：手动粘贴到网页 B 的文本框。
   - 使用顶部 **「新标签页打开 B」**，再自行粘贴 JSON。

### 接口说明（供调试）

- `POST /api/pipeline_a`  
- 表单字段：`image`（文件）、`overlap`、`conf`、`iou`。

## 网页 B：拼接 + 全局 NMS + 导出（Pipeline B）

### 适用场景

- 已有网页 A 返回的 **完整 JSON**，需要对 **整张原图** 合并检测框并 **去掉重叠重复计数**。
- 导出合并后的 **YOLO 格式 txt** 或 **汇总 CSV**。

### 操作步骤

1. 打开 **`http://localhost:5000/b`**（从 A 跳转、侧栏或 A 顶部按钮均可）。
2. 若从 A 点了 **「带着 JSON 去网页 B」**，大文本框一般 **已自动填好**；否则请 **粘贴** 完整 JSON。
3. 设置 **全局 NMS IoU**（默认 `0.35`，与常见部署侧跨 tile 合并一致，可按现场调）。
4. （可选）**「可选：原图画框」** 上传 **与 A 处理时相同的那张原图**，用于在结果里画合并后的框；尺寸应与 JSON 里 `orig_w × orig_h` 一致。
5. 点击 **「运行 pipeline_b」**。
6. 查看 **「合并人数」**、文本框中的 **YOLO 行**、下方预览图（若上传了原图）。
7. 使用 **「下载 merged.txt」**、**「下载 CSV」** 保存结果。

### 接口说明（供调试）

- `POST /api/pipeline_b`  
- **multipart**：`payload`（JSON 字符串）、可选 `image`（文件）、可选 `merge_iou`。  
- 或 **application/json**：整份 payload + 可选 `image_base64`、`merge_iou`。

---

## A → B 推荐闭环

```text
打开 /a → 选大图 → 运行 pipeline_a
       → 点「② 带着 JSON 去网页 B」
       → 在 /b 确认 JSON 已填入 →（可选）选同一张原图
       → 运行 pipeline_b → 查看合并人数 / 下载 txt 与 CSV
```

---

## 与主页单图检测的区别

- **主页 `/`**：整图 **letterbox 到 1280** 做一次推理，适合单张不算特别大的图。
- **网页 A + B**：**滑窗多块推理** 再 **全局 NMS**，更适合 **超大图** 或与训练时 **tile 流程** 对齐的验收方式。

---

## 常见问题

1. **打不开 `/b`、提示无效响应**  
   请确认启动的是 **`person_dataset/app_win.py`**，且已保存包含 `/a`、`/b` 与 `api/pipeline_*` 的当前版本，并 **重启服务**。

2. **B 里合并人数比 A 的 sum_raw 少**  
   属正常现象：`sum_raw` 为各块简单相加，**跨块重复的人**会在 B 的 **全局 NMS** 中被合并。

3. **上传上限**  
   大图受 Flask `MAX_CONTENT_LENGTH`（当前多为 64MB）限制，超限需压缩图片或调配置。
